### 1. Salesforce — "Agentforce Sales: The 24/7 Digital Workforce that Ends the Sales Grind"
- **Publisher:** Salesforce (first-party vendor news)
- **Publication/update date:** 2026 (Spring '26 release cycle; exact day not stated on page)
- **URL:** https://www.salesforce.com/news/stories/agentforce-sales-announcement/
- **Factual claim:** The Agentforce Prospecting Agent builds a daily, prioritized queue of target accounts and contacts, explains a "why now" rationale for each, and drafts personalized outreach using verified data — operating continuously rather than on a rep-initiated basis.
- **Meeting issue it connects to:** The board member's specific question — "why is Northstar not using an AI agent for prospecting" — after seeing an Agentforce demo.
- **What it changes/confirms/deprioritizes:** Confirms the capability the board member likely saw is a real, specific feature (not a vague AI claim), giving Priya's team something concrete to compare against rather than guessing. Directly feeds Priya's task to "confirm which Agentforce capabilities the board member referenced."
- **Relevance score:** 3
- **Credibility/recency note:** First-party vendor announcement — reliable for describing what the feature does, but written as marketing copy; performance claims (e.g., "ends the sales grind") should be treated as promotional, not independently verified. Tied to the 2026 release cycle, so current.
- **Human-review flag:** Major competitive claim

- **Relevance score:** 3
- **Credibility/recency note:** Third-party CRM-consulting site — plausibly has a commercial interest in one platform or implementation services; treat comparative framing as directional, not definitive. Dated to 2026, so current.
- **Human-review flag:** Major competitive claim

### 3. HubSpot Knowledge Base — "Transfer data from other apps using HubSpot Smart Transfer"
- **Publisher:** HubSpot (first-party product documentation)
- **Publication/update date:** Not dated on page (live knowledge-base article, reflects current product state as of access date 2026-07-28)
- **URL:** https://knowledge.hubspot.com/integrations/transfer-data-from-other-apps-using-hubspot-smart-transfer
- **Factual claim:** HubSpot's Smart Transfer tool (Data Management > Data Integration) natively supports importing data from Pipedrive, Zendesk, Mailchimp, Freshdesk, Marketo, and other platforms, starting with a guided data audit.
- **Meeting issue it connects to:** Dana's migration-risk concern and the request for "a practical 90-day migration sequence"; Northstar's current stack is Pipedrive (BD), Mailchimp (newsletters), Zendesk (support) — all three named tools are covered.
- **What it changes/confirms/deprioritizes:** Confirms native migration paths exist for all three of Northstar's systems, which should lower the perceived migration risk Dana raised and can be used directly in Eli's July 24 migration-risk workshop and the sample data model due July 18.
- **Relevance score:** 3
- **Credibility/recency note:** First-party, official product documentation — high credibility for capability claims. No explicit "last updated" date is shown, so confirm the feature is still live before citing it in the workshop.
- **Human-review flag:** None

### 4. HubSpot Company News — "HubSpot's Customer Agent and Prospecting Agent: Now you pay when the task is complete"
- **Publisher:** HubSpot (first-party company news)
- **Publication/update date:** Effective April 14, 2026 (per article)
- **URL:** https://www.hubspot.com/company-news/hubspots-customer-agent-and-prospecting-agent-now-you-pay-when-the-task-is-complete
- **Factual claim:** As of April 14, 2026, HubSpot moved Breeze Customer Agent and Prospecting Agent to outcome-based pricing: Customer Agent at $0.50 per resolved conversation (down from $1.00), Prospecting Agent at $1 per lead recommended for outreach (replacing a flat per-enrolled-contact monthly charge), and a Data Agent at $0.10 per answer. Breeze features are included across all HubSpot plans, with higher tiers unlocking more usage credits.
- **Meeting issue it connects to:** Dana's explicit reluctance to buy "an expensive add-on before the underlying data is cleaned."
- **What it changes/confirms/deprioritizes:** Changes the cost framing for the board conversation: outcome-based pricing (pay only for completed tasks) is a materially different commitment than a flat license fee, which could let the team propose a small-scale AI trial without requiring the full data-cleanup investment up front — worth revisiting Dana's sequencing assumption.
- **Relevance score:** 3
- **Credibility/recency note:** First-party, dated, and recent (April 2026, well within the current reporting window as of July 28, 2026). High credibility for the pricing mechanics; treat performance stats elsewhere in HubSpot's own materials (e.g., resolution rates) as vendor-reported, not audited.
- **Human-review flag:** Pricing
